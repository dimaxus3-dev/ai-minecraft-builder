# Фронтенд: задание

Ты делаешь две страницы. Бэкенд уже работает и не меняется, поэтому пиши по контракту ниже, сначала на
фейковых данных. Живой адрес сервера Дима даст позже; страницы отдаются самим сервером, так что
запросы пиши с относительными адресами (`/api/request`, `location.origin`).

## Правила
- Только папка `static/`. Чистый HTML + JS + Tailwind с CDN (`https://cdn.tailwindcss.com`), без сборки и фреймворков.
- Сначала телефон (mobile-first), потом большой экран.
- `admin.html` не трогать, это страница Димы.
- Перед пушем `git pull --rebase`. Файлы называй ровно так, как ниже: сервер подхватит их сам.

## Страница 1 — `static/index.html` (приоритет, делай первой)
Открывается на телефоне по QR. Человек видит её впервые и за две секунды должен понять, что делать.
1. Заголовок в одну строку: что здесь происходит.
2. Поле ввода (в фокусе, до 300 символов) и кнопка отправки.
3. 3–4 кнопки-подсказки, которые подставляют текст в поле: «маяк», «дракон», «башня с часами», «Golden Gate Bridge».
4. После отправки — живой статус **своего** запроса по WebSocket (сохрани `id` в `localStorage`, показывай только его).
5. Ошибки 400 и 429 — показывай текст из `detail` как есть, там уже написано, сколько ждать.
6. Кнопку 🎤 делай в последнюю очередь и только если останется время.
7. Мелкой строкой внизу: «Powered by open-weight models: Nemotron 3 Super · gpt-oss-20b» и ссылка на
   https://github.com/dimaxus3-dev/ai-minecraft-builder

## Страница 2 — `static/screen.html`
Висит на большом экране зала, читается с десяти метров: тёмный фон, огромный шрифт.
1. Крупно: что строится сейчас, и полоса прогресса по слоям (`done` из `total`).
2. Три счётчика из `stats`: построено, в очереди, всего блоков.
3. Список последних построек: текст запроса и имя автора, если есть.
4. Если очередь пуста — большой QR и призыв отсканировать. Экран сам себя рекламирует.
5. В углу та же строка про открытые модели и ссылка на репозиторий. Если в событии `update` появится поле
   `model`, покажи его рядом с текущей постройкой; пока его нет, не делай вид, что оно есть.

## HTTP API
| Запрос | Тело | Ответ |
|---|---|---|
| `POST /api/request` | `{"text": "маяк", "author": "Имя"}` | объект запроса |
| `GET /api/requests` | — | `{"requests": [...], "stats": {...}, "worker_online": true}` |

Ошибки приходят как `{"detail": "текст для человека"}`: 400 (пустой или слишком длинный текст) и 429
(лимит: один запрос в минуту). Показывай `detail` дословно.

## Объект запроса
```json
{
  "id": 2, "text": "каменная башня с часами", "author": "Дима", "status": "done",
  "created_at": "2026-10-02T10:13:49+00:00", "updated_at": "2026-10-02T10:14:29+00:00",
  "error": "", "program": {"name": "Каменная башня", "size": [11, 26, 11], "parts": []},
  "origin": [-6, -60, -6], "blocks": 1794
}
```
`program` и `origin` равны `null` до генерации, `blocks` равен `0` до конца стройки. Поле `ip` наружу не отдаётся.

## Статусы
| Статус | Что показать человеку |
|---|---|
| `pending` | Ждёт проверки |
| `approved` | Одобрено, в очереди |
| `generating` | Придумываем чертёж |
| `building` | Строится в Minecraft |
| `done` | Готово |
| `rejected` | Отклонено модератором |
| `failed` | Не получилось (причина в `error`) |

## WebSocket
Адреса: `/ws/public` для телефона, `/ws/screen` для экрана. Без авторизации; страница только слушает.
```js
const ws = new WebSocket(location.origin.replace('http', 'ws') + '/ws/public');
ws.onmessage = (m) => {
  const d = JSON.parse(m.data);
  if (d.type === 'init')     { /* d.requests, d.stats, d.worker_online: нарисовать всё с нуля */ }
  if (d.type === 'update')   { /* d.request (может не быть), d.stats, d.worker_online */ }
  if (d.type === 'progress') { /* d.id, d.done из d.total, приходит не чаще двух раз в секунду */ }
};
```
Первым всегда приходит `init` со снимком, потом изменения. `stats`: `{"built": 3, "waiting": 1, "blocks": 5231, "total": 7, "by_status": {}}`.

## Две вещи, которые легко забыть
- **Переподключение.** Сокет рвётся: телефон засыпает, wifi в зале плохой. В `onclose` переподключайся через 1–2 секунды,
  и так бесконечно. Экран зала висит весь день, для него это критично.
- **Не опрашивай API в цикле.** Всё нужное приходит по сокету; `GET /api/requests` нужен только для первой отрисовки.

## Как проверять
Пока нет живого сервера, делай страницы на фейковых данных (объект `FAKE` вверху файла, переключатель одной строкой).
Открывай `index.html` прямо с диска и смотри на телефоне. Для настоящих данных Дима пришлёт адрес.
