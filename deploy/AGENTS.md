# Задача: поднять сервер на VDS (публичный HTTPS-адрес)

**Цель к 14:30:** сервер доступен по `https://IP-через-дефисы.sslip.io`, телефон по мобильному интернету открывает
страницу и админку, воркер с ноутбука Димы подключается к серверу. VDS уже есть (Ubuntu/Debian), так что бесплатно.

Серверу нужен только Python: Minecraft и gdpc на VDS НЕ нужны (проверено). Порт 8000 наружу не открывать:
сервер слушает только 127.0.0.1, снаружи ходит Caddy.

## Что Дима должен тебе дать (лично, не в git и не в общем чате)
1. SSH-доступ к VDS: IP, пользователь, твой ключ добавлен в `~/.ssh/authorized_keys`.
2. Два длинных секрета (`openssl rand -hex 16`, два раза): `ADMIN_SECRET` и `WORKER_SECRET`.
3. `NVIDIA_API_KEY`.
4. Кэш карт (по желанию, ускоряет): Дима отправит `data/osm_cache/` в `/opt/hack/data/osm_cache/`.

## Шаги (на VDS)
1. Код из GitHub (в репозитории должен быть последний коммит от Димы):
   `sudo mkdir -p /opt/hack && sudo chown $USER /opt/hack && git clone https://github.com/dimaxus3-dev/ai-minecraft-builder.git /opt/hack`
2. `.env`: `cd /opt/hack && cp deploy/.env.vds.example .env && nano .env` (заполни три значения «ЗАМЕНИ»; в строках без комментариев).
3. Установка: `cd /opt/hack && sudo bash deploy/setup.sh`. В конце должно быть `active` и `HTTP 200`. Нужен Python 3.10+.
4. Caddy (если ещё не настроен на `127.0.0.1:8000`):
   `sudo cp /opt/hack/deploy/Caddyfile /etc/caddy/Caddyfile && sudo sed -i 's/DOMAIN/1-2-3-4.sslip.io/' /etc/caddy/Caddyfile && sudo systemctl reload caddy`
   (замени `1-2-3-4` на IP сервера через дефисы). ufw: открыты 22, 80, 443 и больше ничего.
5. Скажи Диме адрес. Он впишет в `.env` на ноутбуке `VDS_WS_URL=wss://АДРЕС/ws/worker` и `WORKER_SECRET` и перезапустит воркер.

## Готово, когда (проверь каждый пункт)
- [ ] `systemctl is-active hack` пишет `active`, и после `sudo reboot` сервер поднимается сам.
- [ ] `curl https://АДРЕС/api/requests` отдаёт JSON.
- [ ] С телефона по **мобильному интернету** открывается `https://АДРЕС/` (с замочком, без предупреждений браузера).
- [ ] Открыта админка `https://АДРЕС/admin-ADMIN_SECRET`; запрос, отправленный с телефона, появляется в ней сразу, без перезагрузки.
- [ ] В админке горит «воркер на связи» после подключения ноутбука Димы.
- [ ] Лимит «1 запрос в минуту» работает по настоящим адресам: два телефона из разных сетей оба могут отправить запрос за одну минуту (если второму пишет 429, в сервер приходит 127.0.0.1 вместо адреса клиента, смотри Caddy и `--proxy-headers` в `deploy/hack.service`).
- [ ] Страницы из `static/` отдаются (после твоей работы над ними: `git pull` и `sudo systemctl restart hack`).

## Правила
- Ключи и секреты только в `/opt/hack/.env` (права 600), никогда в git и в общем чате.
- Код в `backend/` и `builder/` не правим без Димы; найденное пиши ему.
- Обновление кода: `cd /opt/hack && git pull && sudo systemctl restart hack` (`.env` и `data/` в git не лежат, не затрутся).

## Если не взлетело
- Логи сервера: `sudo journalctl -u hack -f`. Логи Caddy: `sudo journalctl -u caddy -f`.
- Сертификат не выдаётся: закрыты порты 80/443 или адрес записан неверно (IP через дефисы + `.sslip.io`).
- 502 от Caddy: служба `hack` упала, смотри её лог. Воркер не подключается (код 4003 в логе): разные `WORKER_SECRET`.
- Запасной план, если до 13:30 не вышло: Дима запустит бесплатный туннель на ноутбуке (две команды), VDS тогда не нужен.
