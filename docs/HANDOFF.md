## Как это работает
    телефон (QR -> сайт) -> сервер FastAPI -> очередь SQLite -> модератор (/admin) одобряет
      -> РЕШАТЕЛЬ (первый ответивший слой): 1) чертёж (18 штук, мгновенно) 2) карта OpenStreetMap (2-4 с)
         3) открытая модель + справка Википедии (60-90 с) -> программа постройки (JSON, с пометкой source)
      -> WebSocket -> воркер на ноутбуке -> gdpc -> Minecraft слоями; режиссёр камеры облетает здание,
         пишет название и источник, процент стройки, салют; в простое возит по построенным зданиям.
Запрос начинает разрешаться сразу при отправке (предгенерация), поэтому после «Одобрить» стройка стартует за ~1 с.

## Запуск локально
- Окружение: `~/hackathon/venv` (Python 3.14). Minecraft Java 1.21.4 + Fabric + GDMC HTTP Interface на :9000, мир superflat
  (земля y=-60, `GROUND_Y=-60`).
- Сервер: `./venv/bin/python -m uvicorn backend.main:app --port 8000 --host 127.0.0.1`
- Воркер: `./venv/bin/python -m builder.worker` (камера забирает игрока; при остановке по SIGTERM режим возвращается).
- Страницы: `/` (телефон), `/screen` (экран зала), `/admin-<ADMIN_SECRET из .env>` (модератор, есть галочка «одобрять сразу»).
- Без игры: `python -m builder.blueprints <id> -o out.png` и `python -m builder.preview file.json -o out.png` рисуют картинку.

## Что сделано
- Строитель (`builder/`): примитивы (box, hollow_box, cylinder, sphere, line, roof, arch, cone, dome, repeat), части blueprint и voxels,
  `voxels.py` (программа -> блоки без gdpc), `build.py` (слоями), `placement.py` (участки по спирали), `preview.py` (PNG).
- Чертежи (`builder/blueprints/`): Eiffel, Golden Gate, Transamerica, Taj Mahal, Colosseum, Great Pyramid, Baiterek, Khan Shatyr, Palace of
  Peace, Saint Sophia (Киев), Motherland Monument (Киев) и типовые castle, house, skyscraper, cathedral, pagoda, windmill, lighthouse.
  Папка `landmarks/`: новый файл = новое здание без правок других файлов (есть `_template.py`). Общие слова («замок») срабатывают
  только на короткий запрос.
- Карта (`builder/osm.py`): Nominatim + Overpass (зеркала параллельно), контуры/высоты/крыши в блоки, кэш `data/osm_cache`, только при >=3
  частях `building:part`. Справка Википедии: `backend/research.py`. Запросы без чертежа логируются в `data/unmatched.txt`.
- Модели (NVIDIA API, ключ `NVIDIA_API_KEY` в .env): гонка с отсрочкой 20 с: ultra -> super -> gpt-oss-20b; не меньше 3 материалов (мягкий повтор).
- Сервер (`backend/`): очередь, админка, лимит 1 запрос в минуту (IP хранится хешем), публичные ответы без `ip` и без блоков.
- Страницы (`static/`): дизайн Ethan'а, подключены к живому API (статусы по WebSocket с переподключением, QR на экране, источник здания).
  Убран его английский валидатор (он отвергал русские и украинские запросы).
- Показ: чат без «Teleported» (gamerule sendCommandFeedback/logAdminCommands/commandBlockOutput = false), всегда полдень и ясно.
- Деплой: `deploy/` (systemd `hack.service`, `Caddyfile`, `.env.vds.example`, `setup.sh`) и задание для помощника `deploy/AGENTS.md`.
- Задания для ассистентов лежат в репозитории: `CLAUDE.md` и `AGENTS.md` (для Codex) в корне, `static/`, `deploy/`.

## Что учесть (находки, чтобы не повторять)
- Модель сама рисует здания плохо (её Эйфелева башня была четырьмя столбами): поэтому слои «чертёж -> карта -> модель».
- NVIDIA API нестабилен: ultra и super часто в таймаут, gpt-oss быстрый, kimi-k3 мёртв; ASR/Whisper на этом ключе нет.
- Overpass: живы `overpass.openstreetmap.fr` и `overpass-api.de`; запросы идут ко всем сразу.
- GDMC `runCommand` возвращает `[(успех, сообщение)]`; команды только с абсолютными координатами (`~` считается от (0,0,0)).
- Моя песочница не открывает произвольные адреса (в том числе VDS) и ломает проверки доступности: им не верить.
- Версии в `requirements.txt` сняты с рабочего venv (3.14); на старом Python скрипт ставит свежие.
